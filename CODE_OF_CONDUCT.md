# Community code of conduct

Everyone should be able to ask questions, learn, and contribute without harassment.
Be considerate, give specific and constructive feedback, and respect different
backgrounds and experience levels. Critique ideas and code rather than people.

Harassment, threats, discriminatory language, sexual attention, impersonation,
spam, and sharing another person's private information are not acceptable in
issues, pull requests, discussions, or other project spaces.

Maintainers may edit or remove harmful content, warn participants, limit access,
or ban repeated or serious violations. They should explain decisions privately
when possible and handle reports confidentially, sharing only what is necessary
to investigate and respond.

To report a concern, ask a repository maintainer for a private contact channel.
If no contact is listed on their GitHub profile, open an issue titled “Private
maintainer contact requested” without names, evidence, or incident details; share
the report only after the maintainer supplies a private channel. If the concern
involves a maintainer, GitHub's profile/content reporting tools provide an
independent reporting route. Do not publish reports about other participants.
